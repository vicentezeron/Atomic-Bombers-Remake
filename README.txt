Atomic Bombers (web remake)
===========================
Quick start: open index.html in a browser. It works offline.

Installable app: upload this whole folder to any static web host over https
(GitHub Pages, Netlify, Cloudflare Pages, your own server). Open the address once;
the browser then offers Install (Chrome/Edge: address bar icon or menu; Safari on iOS:
Share > Add to Home Screen). After that it opens in its own window and works offline.

Online play (Play online > Create a room, then share the code) connects browsers directly
through the free PeerJS broker, so it needs https hosting and an internet connection.
The shared hall of fame and community worlds only exist in the version that runs inside Claude.
Settings, stats and custom levels are stored in the browser you use.
